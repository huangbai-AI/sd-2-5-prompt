## 1. 多模态参考

先建立素材角色表，不要只写“参考所有素材”。

```text
素材声明 = 素材编号 + 正向职责 + 生效时段 + 禁止迁移项
```

示例：

```text
@图1锁定主角脸、发型与服装，全片生效；不参考图中背景和文字。
@图2锁定产品外形与材质，全片生效；不改变比例与结构。
@视频1只参考8—12秒的跑动重心和侧向跟拍，不复制人物、场景、品牌或声音。
@音频1作为完整背景音乐，0秒开始，结尾自然收束；对白始终高于音乐。
```

同一素材承担过多职责时拆开描述。多次引用时重复写清“只参考什么”。

## 2. 15 秒与 30 秒

### 15 秒

推荐节奏：

```text
0—2秒：主体/产品/冲突立即出现
2—5秒：第一动作或卖点
5—9秒：推进或关系变化
9—12秒：高潮或证明
12—15秒：落点、反应或英雄画面
```

这只是原创内容的默认骨架。反推样片时使用真实切点。

### 30 秒

推荐结构：

```text
0—3秒：钩子与关系建立
3—8秒：第一阶段
8—13秒：升级
13—18秒：变化或换位
18—24秒：高潮
24—28秒：结果
28—30秒：稳定收尾
```

动作片可以用更多段，但每段必须继承上一段的位置与状态。情绪片可以用更少段，延长表演细节。

## 3. 原片直接反推

必须同时检查：

- 视频总时长、画幅、帧率。
- 真实剪辑切点。
- 每个镜头的首帧与尾帧。
- 人物、服装、产品和场景。
- 动作是否真实存在。
- 口播、字幕、环境声和音乐。

输出规则：

1. 使用真实时间切点，而不是平均分段。
2. 只描述画面中能确认的动作。
3. 区分硬切和无缝转场。
4. 不把镜头外推断写成事实。
5. 不为了“更精彩”添加抛接、击掌、旋转、特技或新对白。
6. 用户要求延伸时，另建“创意延伸版”，不要覆盖直接反推版。

## 4. 一镜到底与切镜

### 一镜到底

写出摄影机连续路线、人物连续路线、遮挡关系和速度变化。时间段只是阶段，不代表剪辑。

```text
全片一个连续镜头，不硬切、不瞬移。摄影机从A点出发，跟随主体经过B点，绕过前景C，最后停在D构图。
```

### 切镜

每个镜头说明：开始构图、主要动作、切出条件。不要在一个时间段里同时要求固定机位、360度环绕、无人机俯冲和主观镜头。

## 5. 视频延长

只描述新增部分：

```text
延长提示词 = 原片末帧状态 + 新增时长 + 衔接动作 + 新增事件 + 结束状态 + 连续性限制
```

模板：

```text
在原视频末尾向后延长[X]秒。保持原视频同一人物、服装、场景、光线、镜头方向和动作速度。原片末帧中[状态]继续自然发生；随后[新增动作]；最后停在[结束构图]。不修改原片已有部分，不生硬切镜，不凭空增加人物或物体。
```

需要切换场景时，明确一个可见转场载体和前后同方向运动。

## 6. 智能编辑

```text
编辑提示词 = 生效时段 + 定位方式 + 目标对象 + 从A变成B + 保留项 + 声音要求
```

模板：

```text
在[0—8秒/全片]，把[红框内/画面左侧/人物手中]的[目标对象]从[A状态]替换为[B状态]。只修改该对象，保持人物脸、动作、构图、背景、光线、摄影机运动和其他物体完全不变。[保留/去掉]原声音与字幕。
```

局部编辑要写“只修改什么”和“必须保留什么”，防止整片重绘。

## 7. 白模渲染

### 粗白模

用于动作骨架、站位、运镜和空间关系：

```text
粗白模提示词 = 参考声明 + 模型到角色映射 + 时间轴动作 + 场景替换 + 风格材质 + 连续性收束
```

明确每个几何模型对应哪个角色或道具，并写清四肢、翅膀、尾巴等完整动作链。

### 细白模

用于已有模型的材质、光影与风格渲染：

```text
细白模提示词 = 渲染目标 + 分时段材质/光影 + 场景 + 特效 + 不保留辅助线 + 全局一致性
```

禁止把轨迹线、坐标轴、相机锥体、灰模材质或视窗界面带入成片。
