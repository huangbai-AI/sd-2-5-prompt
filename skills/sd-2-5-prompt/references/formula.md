## 1. 一句话公式

```text
提示词 = 主体 + 风格 + 时间线 + BGM + 限制
```

不额外增加“目标、锁定、声音、连续性”等一级模块。需要的内容直接归入这五部分。

## 2. 五部分写法

### 主体

```text
主体 = 主角或产品 + 场景 + 核心事件 + 固定身份 + 参考素材职责
```

- 主角：年龄、外貌、服装、人数和关系。
- 产品：类别、外形、颜色、材质、结构和数量。
- 场景：地点、时间、天气和关键空间关系。
- 参考：每张图、视频或音频只负责什么，不负责什么。

没有参考素材时省略素材职责，不要写空占位。

### 风格

```text
风格 = 时长 + 画幅 + 清晰度 + 成片形式 + 光线色彩 + 质感 + 镜头节奏
```

示例：15 秒、16:9、4K、真人电影级广告；正午硬光与高饱和橙蓝色；快速硬切、微距与低机位跟拍交替。

### 时间线

```text
【开始—结束秒】起始状态 + 可见动作 + 镜头拍法 + 结束状态
```

动作使用可以拍摄的动词：抬手、转身、奔跑、打开、倒入、碰撞、落地。不要只写“很燃、很高级、非常精彩”。

### BGM

```text
BGM = 音乐类型 + 速度/BPM + 核心乐器 + 情绪曲线 + 节拍同步 + 结尾方式
```

需要对白或音效时，继续写在 BGM 段内：

```text
对白 = 说话人 + 语言 + 原文 + 时间 + 情绪 + 口型
音效 = 关键动作 + 声音质感 + 与音乐的层级
```

### 限制

```text
限制 = 身份稳定 + 产品稳定 + 物理正确 + 摄影正确 + 文字/品牌 + 声音边界
```

只选本条最相关的 3—8 项。普通生活方式广告不需要写复杂战斗规则。

## 3. 可直接复制的模板

```text
【主体】
[同一位人物/同一件产品]在[场景]完成[核心事件]。[人物、产品、场景的固定特征]。[如有参考素材：@图1负责……；@视频1只参考……；@音频1负责……。]

【风格】
生成一支[时长]秒、[画幅]、[清晰度]的[真人/动画/CG/混合]视频。[光线、色彩、材质和情绪]。[剪辑与镜头节奏]。

【时间线】
【0—X秒】[起始状态]；[主体完成动作]；[景别和一个主运镜]；结束时[明确状态]。
【X—Y秒】[承接上一段状态]；[主体完成动作]；[景别和一个主运镜]；结束时[明确状态]。
【Y—结尾】[高潮或结果]；[镜头拍法]；最终停在[英雄画面/动作落点]。

【BGM】
[音乐类型]，[速度或 BPM]，[核心乐器]；[从开场到高潮的变化]；在[关键时间点]与动作同步；结尾[停止/拖尾/定音]。[对白与关键音效，如无则写无对白。]

【限制】
避免[3—8个最容易出现的问题]。
```

## 4. 15 秒与 30 秒时间线

### 15 秒

```text
0—2秒：主体、产品或冲突立即出现
2—5秒：第一动作或卖点
5—9秒：推进、转场或关系变化
9—12秒：高潮或效果证明
12—15秒：结果与稳定收尾
```

通常写 4—6 段。原片反推按真实切点，不强行套平均时长。

### 30 秒

```text
0—3秒：钩子与关系建立
3—8秒：第一阶段
8—13秒：升级
13—18秒：变化或换位
18—24秒：高潮
24—28秒：结果
28—30秒：稳定收尾
```

通常写 5—8 段。情绪片可减少段数，动作片可增加段数，但时间必须连续。

## 5. 复杂动作补充规则

只有打斗、追逐、抛接、液体喷射或多人换位时，在相关时间段补充：

```text
谁发起 + 从哪里出发 + 沿什么路径 + 作用于谁 + 最后落在哪里
```

镜头必须让动作关系可追踪：

- 发射前看见发起者的动作。
- 飞行物从发起者身边出现。
- 目标从正确来向受击或防守。
- 换位时用双人广角交代过程。
- 武器飞行时不越轴、不突然反向。

## 6. 最终检查

- 是否只有“主体、风格、时间线、BGM、限制”五个一级部分。
- 时间轴是否从 0 秒连续覆盖到结尾。
- 人物、产品和场景是否前后一致。
- 每段是否只有一个主要动作和一个主要运镜。
- BGM 是否写明速度、乐器、情绪曲线和结尾。
- 限制是否只针对真实风险。
